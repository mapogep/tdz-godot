# Tower Defense / Zombie

Кооперативный tower defense с лабиринтом из стен и режимом FPS из турели. Браузерная игра: TypeScript, Three.js (клиент), Node.js + WebSocket (авторитетный сервер). Полное ТЗ — в [main.md](main.md).

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm start
```

Откройте <http://localhost:7777>. `npm start` собирает клиент и запускает сервер, который раздаёт игру и принимает игроков на одном порту (7777, меняется через `PORT`).
На Windows можно просто запустить `play.bat`.

### Игра вдвоём (co-op)

1. Host запускает `npm start`.
2. Второй игрок открывает `http://<IP-хоста>:7777` в браузере. Первый подключившийся становится Host, остальные — гости.
3. Если игроки не в одной сети, на роутере нужно пробросить порт 7777. В Windows Firewall откройте порт (PowerShell от администратора):

```bash
New-NetFirewallRule -DisplayName "TD1 (7777)" -Direction Inbound -Protocol TCP -LocalPort 7777 -Action Allow -Profile Private
```

## Как играть

Цель — выжить как можно больше волн. Зомби идут из **западных** ворот (зелёный маркер) к **восточным** (красный). Если хоть один дошёл — город уничтожен.

**Только Host** во время подготовки: строит и сносит стены, ставит/переносит/продаёт/улучшает турели, запускает волну. Остальные игроки могут занимать любые свободные турели и стрелять из них.

| Действие | Управление |
| --- | --- |
| Камера | WASD / стрелки, ПКМ или СКМ + мышь, колесо — zoom |
| Инструменты | `1` выбор, `2` стена, `3` снести, `4` турель, `5` пулемёт, `6` ракетомёт, `7` огнемёт (или кнопки внизу) |
| Строить | ЛКМ (стены можно «рисовать», зажав кнопку) |
| Отмена | ESC или ПКМ (без перетаскивания) |
| Турель | ЛКМ по турели → панель: улучшить / продать / переместить / FPS |
| FPS | мышь — прицел (360° без рывков), ЛКМ (можно держать) — огонь. Оружие видно перед вами. ESC снимает захват мыши (игра ставится на паузу, клик — продолжить), второй ESC — выйти из турели |

Правила:
- Турель можно поставить на землю или на стену. Турель на земле не блокирует проход, но зомби, у которых она на пути, останавливаются и разрушают её; турель на стене недосягаема. Между волнами турели чинятся бесплатно.
- Стены нельзя ставить так, чтобы полностью перекрыть путь (сервер проверяет A*).
- Ручной огонь наносит ×2 урона (`fpsDamageMultiplier`).
- Продажа турели возвращает 50% вложенного (база + все улучшения).
- Подготовка длится 120 секунд, но волну можно начать раньше.
- Игра автоматически сохраняется в начале каждой подготовки (`save-<порт>.json`) и продолжается после перезапуска сервера. `TD_SAVE=off` отключает сохранение.

## Оружие и зомби

**Оружие:** базовая турель, пулемёт (скорострельный, с разбросом), ракетомёт (взрыв по площади, урон рассеивается от эпицентра к краю, поджигает), огнемёт (короткий конус, урон убывает с расстоянием, поджигает всех). Оружие покупается кнопками внизу (цена на кнопке); бесплатный запас из 3 турелей — только для базовой. Подробные характеристики — в [main.md](main.md#37-виды-оружия-и-зомби-v3).

**Зомби:** средний, быстрый (мало HP, 3 м/с) и толстый (медленный, очень много HP, сильно бьёт турели). Турели на земле они обходят и ломают только если другого пути нет. Состав ближайшей волны показан на HUD.

## Настройка баланса

Все числа — в [packages/shared/src/config.ts](packages/shared/src/config.ts): размер поля, время подготовки, стартовые ресурсы, цены, награда за зомби, HP и скорость зомби, формулы характеристик турелей по уровням (`turretStats`) и др. Менять код логики не нужно.

## Разработка

```bash
npm run dev        # сервер (:7777, перезапуск при правках) + Vite dev-клиент (http://localhost:5173)
npm test           # unit-тесты (путь, строительство, экономика, бой, сохранение)
npm run typecheck  # проверка типов всех пакетов
npm run e2e        # сетевой смоук-тест: 2 клиента против запущенного сервера (ws://localhost:7777 или свой адрес аргументом)
npm run balance    # симулятор баланса: как далеко заходит «разумный игрок» с разным оружием
TD_MONEY=6000 TD_WAVE=8 npm run serve   # песочница: стартовые деньги и волна для знакомства с оружием
```

Структура:

```
packages/shared   конфиг, сетка, A*, протокол сообщений (общий код клиента и сервера)
packages/server   авторитетный сервер: GameSession → менеджеры (Build, Turret, Zombie, Wave,
                  Economy, GameState, Player, Navigation), NetworkManager, SaveManager
packages/client   Three.js: SceneView, Hud, Input, Effects, Sfx (звуки синтезируются), i18n (RU/EN)
```

Сервер — единственный источник истины: клиент шлёт только намерения (клик по клетке, прицел, «огонь»), а деньги, урон, смерть зомби, проверку пути и старт волн решает сервер.

## Ресурсы и лицензии

- 3D-модели зомби, машин, руин, лагеря, природы и обломков — Kenney (Graveyard, Tower Defense, Car, City, Nature, Prototype, Blaster Kit), лицензия CC0, единый постапокалиптический вид за счёт цветокоррекции, см. `packages/client/public/assets/models/CREDITS.txt`. Если файлы не найдены, игра рисует процедурные модели.
- Текстуры земли, камня и дерева, небо, заставка и иконки сгенерированы StableDiffusion XL (`packages/client/public/assets/tex`). Если файлов нет, рисуются процедурные текстуры (`textures.ts`). Звуки синтезируются в браузере.
